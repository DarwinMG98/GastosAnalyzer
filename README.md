# 📊 GastosAnalyzer

Una aplicación interactiva construida con **Python** y **Streamlit** para el análisis de gastos personales desde archivos CSV.

## 🚀 Funcionalidades

- 📂 Carga de archivos `.csv` con tus gastos
- 📊 Gráfico de pastel: distribución por categoría
- 📈 Gráfico de líneas: evolución de gastos por fecha
- 📅 Filtro por rango de fechas
- 📥 Exportación de reportes en formatos **CSV** y **PDF**

## 🛠️ Tecnologías utilizadas

- Python
- Pandas
- Matplotlib
- Streamlit
- FPDF
